<Card System>

카드 시스템에 대한 대대적인 공사 진행.
프로젝트의 코드를 더 진행하기 전에 토대를 완성 한 이후 진행하는 것이 더 효율적이라고 판단.
해당 문서를 기반으로 카드 시스템 및 상호작용 구조 개편. (기획이자 구현 방향성)

-------------------------------------------
#Element

카드 속성: [불, 물, 땅, 바람 / 얼음, 번개, 빛, 어둠] - (일반/특수) 
카드 속성 구조
CardElemental (또는 SkillElemental)
{
	CE_Normal Fire				( CardElemental->CE_Normal->Fire )	
	CE_Normal Water				
	CE_Normal Earth			
	CE_Normal Wind			

	CE_Special Ice			
	CE_Special Lightning	
	CE_Special Light		
	CE_Special Dark			
}

지형 속성: [불, 물, 땅] / [증발(불+물), 진흙(물+땅)] / [불지옥, 해일, 지진, 얼어붙은 땅, 폭풍, 성역, 심연] - (일반 / 복합 / 특수)
지형 속성 구조: 
TileElemental
{

	TE_Special FrozenGround

	TE_Special Sanctuary	
	TE_Special Abyss		
}

#Skill

소모 AP
지정 범위: 타일 기준 범위(사거리) 존재, 장애물 판단 필요(장애물 지정 불가)
지정 방식: Tile(타일 지정 - 1x1, 1x5, 십자가, 3x3 등 다양한 범위 지원), Snap(대상 지정 - 적군 지정, 아군 지정, 자신 지정)
발동 타입: 타일 지정 투사체, 대상 지정 투사체, 타일 지정 즉발, 대상 지정 즉발

내용물(로직): 공격, 방어, 버프, 디버프, 회복, 소환 등 다양한 스킬 내용물 지원 --> 베이스 클래스를 상속받아 하위 스킬 클래스에서 구현?
내용물(설명): 로직에 대한 설명 텍스트를 직접 입력 (포맷이 가능하도록 구현 필요)

원하는 개발 방식: 스킬의 공격력 등 수치를 에디터에서 직접 입력 가능하도록 구현하고 싶음. 해당 수치는 텍스트에 자동으로 포맷되어 카드 설명에 표시되도록 구현, 실시간으로도 적용.

#Card Data

카드의 정보를 담은 데이터 에셋 클래스.
ID, 이름, 카드 이미지, 카드 속성, 카드 등급, 카드 가격, 카드 타입, 지정 방식, 카드설명 등의 정보

ID: 카드 고유 ID
이름: 카드 이름
카드 이미지: 카드에 표시될 이미지

카드 속성: CardElemental
카드 등급: Common, Rare, Epic, Legendary 등 다양한 카드 등급 지원 --> Widget에서 일반, 코팅, 반짝이, 홀로그램 등으로 카드 등급 표현 가능

소모 AP  --> 스킬 소모 AP를 따라간다.
카드 타입 --> 스킬 타입을 따라간다.		공격, 방어, 버프, 디버프, 회복, 소환 등 다양한 카드 타입 지원
지정 방식 --> 스킬 지정 방식을 따라간다.	Tile(타일 지정 - 1x1, 1x5, 십자가, 3x3 등 다양한 범위 지원), Snap(대상 지정 - 적군 지정, 아군 지정, 자신 지정)
카드 설명 --> 스킬 텍스트를 따라간다 or 직접 입력

-------------------------------------------
#Card Actor

게임 내 카드의 외형 및 상호작용을 담당하는 액터 클래스. --> 데이터에 따라서 특별한 커스텀 없이 자동적으로 카드의 외형이 변경될 수 있도록 설계(또는 블루프린트로 카드마다 일일히 조정). 
Card Data, Mesh, Material, Widget(전체 카드 이미지), VFX/SFX

Mesh -> Material : Card Data에서 가져온 카드 속성에 따라 메쉬의 머티리얼을 변경
카드 코팅 Material : Card Data에서 가져온 카드 등급에 따라 코팅 머티리얼을 변경 (Widget의 위에 덮어 씌울 수 있어야함. 가능한가?)
VFX/SFX: 시전 대기 중 표시될 마법진, 발동 시 표시될 이펙트, 발동 시 재생될 사운드 등 --> Skill Data 또는 Card Data에 삽입된 VFX/SFX를 가져와서 재생
Widget: 카드 이미지, 카드 속성, 카드 등급, 카드 설명 등을 표시하는 위젯. --> Card Data에서 가져온 정보를 기반으로 위젯의 내용을 자동으로 변경

마석: 스킬 서식 모디파이어, 스킬의 수치 조정 또는 투사체를 여러개 발사하는 등의 정보가 담겨야함. --> 인게임 내에서 추가되는 요소임

*게임 도중의 카드 액터들이 디스크에 기록되어야하며, 마석 여부, 종류도 기록된다.
*런 종료 시 해당 런에서 사용된 카드 액터들의 정보가 디스크에 기록되어야하며, 마석 여부, 종류도 기록된다.
*런을 중간에 종료하고, 다시 불러올 때, 기록된 카드 액터들의 정보가 불러와져야함. (마석 여부, 종류도 불러와져야함)

##Card Interaction

-------------------------------------------
#Card Deck

인게임에서 플레이어가 소유중인 카드 액터들의 집합체. 
UI를 통해 자신이 어떤 카드를 소유하고 있는지, 덱 내의 카드 리스트를 보여주는 위젯을 표시 가능.

-------------------------------------------
#Draw Pile

전투 중 상황에서의 뽑을 카드 더미.
UI를 통해 뽑을 카드 더미 내의 카드 리스트를 보여주는 위젯을 표시 가능.

-------------------------------------------
#Discard Pile

전투 중 상황에서의 버려진 카드 더미.
UI를 통해 버려진 카드 더미 내의 카드 리스트를 보여주는 위젯을 표시 가능.

-------------------------------------------
#Hand

전투 중 상황에서의 플레이어가 현재 소유중인 카드들.
플레이어 캐릭터의 카메라에 Attach된 SceneComponent를 기준으로 존재한다. (카메라에 따라 카드들이 고정된 위치에 표시될 수 있도록)

<기본 룰>
내 턴 시작 시:	카드를 뽑아 손패에 추가
내 턴:			카드를 사용하여 소모 AP를 소모, 사용한 카드는 버려진 카드 더미로 이동
내 턴 종료 시:	손패에 남아있는 카드는 버려진 카드 더미로 이동
핸드의 카드 수량 제한:	최대 10장

<PlayerController의 핸드 상호작용 상태>
-> Hovering: 
	해당 상태에서는 IA_MouseMove에서 라인 트레이스를 통해 카드 액터를 감지하고, 감지된 카드 액터의 3D 오프셋을 조정하여 카드가 살짝 떠오르는 효과를 준다. 
	이 때, 떠오르는 효과는 카드 액터의 Tick에서 Lerp를 통해 Smooth하게 구현. (Tick: 현재 위치 기준 오프셋을 더한 Lerp)
	이 상태 외에는 호버링 효과 x. (상태를 기반으로 다른 로직이 호출되므로)

-> Selecting: 
	Hovering 상태에서 마우스 클릭 시, 마우스의 월드 좌표를 카메라 상대 좌표로 변환, 좌표를 카드 액터에게 전달하여 카드 액터가 마우스를 따라 움직이도록 구현.
	이 상태에서 IA_MouseMove에 따라 핸드의 카드 위치 임의 정렬 가능. (상태를 기반으로 PlayerController의 IA_MouseMove에서 카드 상호작용 컴포넌트 호출)
	만약 마우스를 뷰포트의 하단 3분의 1 지점(또는 사각영역 개발자 임의 지정)으로 넘기면 핸드를 선택된 카드 액터를 제외하고 재정렬한다. (이것으로 카드 사용 여부 판단)
	이 상태에서 마우스 클릭을 해제 시, 해제한 위치가 뷰포트의 하단 3분의 1 지점을 넘어가는 지 판단 후, 
	넘지 않으면 임의 정렬 로직을 그대로 실행 후 Hovering 상태로 전환.
	넘어가면 Waiting 상태로 전환 후 카드 스킬의 '지정 방식'에 따라 분기
	- 즉발(지정 없음)	-> Waiting 상태로 전환 후 스킬 발동 로직 및 애니메이션 수행
	- 지정 필요		-> Waiting 상태로 전환 후 카드 이동 애니메이션 수행

-> (Waiting): 
	애니메이션 진행 중 또는 다양한 상황(적 턴 등)에서 입력 대기 상태.
	Selecting에서 넘어온 경우 
	- 즉발(지정 없음)	-> 스킬 발동 로직 및 애니메이션 수행 후, 카드 액터를 버려진 카드 더미로 이동 후 Hovering 상태로 전환.
	- 지정 필요		-> 카드 액터가 화면 중앙부로 이동 후, 회전/이동 애니메이션으로 카드 액터가 화면 왼쪽에 위치하게 된다. 
						(카드 애니메이션은 타임라인 기반으로 오프셋과 회전값을 에디터에서 지정할 수 있게 한다.)

-> Casting: 
	Selecting에서 캐스트를 취소하지 않았을 경우, 발동할 스킬의 대상/범위를 지정하는 로직을 수행한다. 
	이 상태에서 (우클릭 더블클릭 / 캐스팅 중인 카드 클릭으로) 캐스팅을 취소할 경우, 
	카드 액터를 원래 위치로 되돌리는 로직을 실행 후 Hovering 상태로 전환.
	범위를 지정했으면 발동 로직 수행
	발동 로직: 스킬을 발동하고, 카드 액터를 버려진 카드 더미로 이동 후, Hovering 상태로 전환.

-> (Moving):
	플레이어의 그리드 이동 활성화 상태이며, 해당 상태에서는 핸드 상호작용이 불가능하다. (상태 기반 차단)

** Hovering, Selecting, Casting은 카드 액터의 상태이기도 함
* Hovering, Selecting 상태의 카드는 Tick에서 Lerp를 통해 Smooth하게 위치를 조정한다. (카드 액터의 Tick에서 현재 위치 기준 오프셋을 더한 Lerp)
* Waiting에서는 타임라인 기반으로 카드 액터의 위치와 회전을 조정한다. (오프셋과 회전값을 에디터에서 지정해서 타임라인에 넘겨줄 수 있게 구현)
* Casting 상태의 카드 액터는 좌클릭(캐스팅 중인 카드 선택)을 통해 캐스팅 취소가 가능하며, 우클릭 더블클릭을 통해서도 캐스팅 취소가 가능하다.
	(캐스팅 취소시 취소된 카드를 핸드의 마지막 인덱스에 넣고, Tick에서 Lerp를 통해 Smooth하게 위치를 조정한다.)

<상태 기반 입력처리 분기>
IA_MouseL: 
	- Moving 상태에서 클릭 시 (범위 타일 내/외)		-> 이동 수행/이동 취소, Hovering 상태로 전환
	- Hovering 상태에서 카드 액터 클릭 시			-> Selecting 상태로 전환
	- Casting 상태에서 캐스팅 중인 카드 액터 클릭 시	-> 캐스팅 취소 로직 수행, Hovering 상태로 전환
	- Selecting 상태에서 클릭 입력 해제 시			-> 위에 서술한 로직에 따라 Hovering/Waiting 상태로 전환

IA_MouseR: 
	- Casting 상태에서 더블클릭 시					-> 캐스팅 취소 로직 수행, Hovering 상태로 전환

IA_MouseMove: 
	- Hovering 상태에서 핸드의 카드 위로 이동 시		-> 카드 액터의 3D 오프셋을 조정하여 카드가 살짝 떠오르는 효과를 준다. (Tick에서 Lerp를 통해 Smooth하게 구현)
	- Moving 상태에서 마우스 이동 시				-> 이동 범위 타일 내/외를 판단하여 이동 가능/불가 표시
	- Selecting 상태에서 마우스 이동 시				-> 카드 액터가 마우스를 따라 움직이도록 구현. (핸드의 카드 위치 임의 정렬 가능)
