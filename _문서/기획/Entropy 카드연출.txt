<카드>

3d액터 / UMG / 머티리얼

하이라이트 연출: 카드 외곽선 하이라이트 (선택 등).
특수 조건이 만족되었거나 비용이 감소된 카드 외곽선 색상 변경.

손패 연출: 가로 일자/가로 아치형 등. 카드 드래그 앤 드롭으로 셔플 가능하게 구현.

사용 연출: 손패 드래그앤드롭
	-> (드래그 중 카드 주위 외곽선 + 더 빛나는 이펙트 구현, 외곽선은 홀드와 똑같지만 빛 알갱이 이펙트 추가)
	-> (카드가 화면 중앙으로 이동 후 앞뒤로 찰지게 회전하며 화면상애서 왼쪽 중앙에 이동)
	-> 시전 및 조준대기(시전 이펙트 천천히 회전하는 마법진 등 발생)
	-> 대기중이던 카드 클릭으로 시전 취소 / 범위 내 타일 지정으로 카드 사용
	-> 범위지정 완료 시 플레이어 모션, 마법진, 스킬(투사체, 버프 등등) 이펙트 발생. 
	(사용된 카드는 버린 카드 더미로 이동)

시전 취소 연출: 취소 시 손패 맨 왼쪽으로 스윽하고 자연스럽게 이동. 
	-> 회전중이던 마법진도 자연스럽게 투명해지며 사라짐. 
	-> 플레이어 시전 대기 모션(바람에 휘날리는 등) 역시 취소되며 idle로 복귀

카드 사용 이펙트: 범위 지정이 끝나면 화면 상에서 대기 중이던 카드 위 마법진이 빛을 내며 사라짐 
	-> 플레이어 손or지팡이 앞에서 1초간 해당 마법진 이펙트 발생 
	-> 동시에 화면상의 대기중이던 카드는 오른쪽부터 서서히 빛 알갱이로 화하며 사라진다 
	-> 거의 동시에 버린카드 더미에 빛알갱이들이 모여드는 느낌의 이펙트가 발생.
	(이펙트는 카드가 사라지기 시작할 때 모두 동시에 발생)

뽑을카드더미 연출: 드로우 단계 시 뽑을카드더미가 빛을 내뿜으며 손패에 카드들이 들어온다. 
	이때 손으로 들어오는 카드들은 빛 알갱이들이 모여 카드로 변화하는 듯한 연출을 보여준다. 
	카드 하나씩 뽑을때마다 짧은 간격의 딜레이 주기, 첫 드로우 카드 위치는 손패 가운데(빛이 손패 가운데서 발생 시작). 
	뽑은 순서대로 왼쪽부터 정렬됨(오른쪽으로 쌓임) 드로우로 인한 정렬이 끝난 이후에 카드에 간섭 가능. 
	카드 효과로 인한 드로우는 사용된 카드 속성에 따라 이펙트가 다르게 연출된다. 	
	(아예 다른 이펙트 사용, 정렬 로직은 같음, 이때도 카드 간섭 제한걸고 드로우 끝나면 가능하게)

버린카드더미 연출: 어떤 방식으로든 버린카드 더미에 카드가 추가될시 발생하는 이펙트다. 
	버린카드더미가 빛나며 빛 알갱이들이 들어오는 느낌의 이펙트가 발생된다.

덱 셔플 시 연출: 버린카드더미의 카드들이 뽑을카드더미로 돌아오며 셔플되는 연출을 의미. 
	뽑을카드더미에 카드가 추가되는 연출은 버린카드더미에 카드가 추가되는 연출을 동일하게 사용하며, 
	이는 버린카드더미에서 카드가 사라지는 연출 역시 마찬가지이다. 
	셔플이 끝나기를 대기하며, 끝난 이후 드로우가 시작된다. (카드 간섭 제한은 드로우와 마찬가지)

카드더미 공통 UI: 미니 3d카드 뒷면이 쌓인 모습. 3d로는 최대 10장만 표시. 
	카드 갯수가 10장 이하로 떨어질때마다 실제로 미니카드가 이펙트(이전에 말한)와 함께 사라짐. 
	맨 밑에 점선 사각형으로 0장 표시 가능. 가운데에 카드 갯수가 텍스트로 써있음. 
	호버링시 3D더미에 하이라이트 외곽선이 표시된다. 
	호버링 시작 시 카드더미가 들썩이는 연출, 
	호버링 지속 시 잔잔하게 흔들리는 연출을 주도록 한다. 
	클릭이 가능하며 클릭 시 해당 더미에 존재하는 카드들의 리스트를 보여준다. 최초에는 정렬하여 보여준다. 
	(공간 상에 자유롭게 놓을 수 있게 마우스로 임의배치 가능 + 호버링 시 외곽선 하이라이트, 카드 클릭 시 자세히 보기 기능 존재)
